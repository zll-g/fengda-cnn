# 样本数据查看工具

## 功能

- 使用 C# WinForms 开发。
- 直接读取项目根目录下的原始 historian `csv` 文件。
- 上方图表显示输入参数折线。
- 下方图表显示目标数据折线。
- 目标图右侧显示第一版 `FGR` 调节建议。
- 左右按钮每次移动 `1` 秒时间窗口。
- 所有参数都可以通过右侧勾选列表显示或隐藏。
- 支持从下拉框选择项目目录中的 CSV，也支持手动选择指定文件。

## 运行

```powershell
cd viewer
dotnet run
```

## 当前窗口定义

- 输入窗口：当前时间开始的 `60` 秒
- 目标窗口：输入窗口之后的未来 `60` 秒

图中多条曲线按当前窗口内各自最小值和最大值归一化显示，右侧图例会显示每条曲线在当前窗口内的实际取值范围。

## FGR 建议模块

当前版本为预测后的规则建议模块，不是自动闭环控制。

建议逻辑读取 ONNX 模型输出的未来 `60` 秒 `NOx / O2 / NO2` 预测曲线，并结合当前 `FGR` 调节阀开度和 `FGR` 风机频率生成建议。第一版优先遵守安全边界，在安全范围内尽量压低 `NOx`。

默认约束：

- `NOx` 控制目标：`100 mg/m³`
- `NOx` 运行经验下限：`10 mg/m³`
- `O2` 硬下限：`3.0%`
- `O2` 优化裕量：`4.2%`
- `NO2` 上限：`50 mg/m³`
- `FGR` 调节阀建议上限：`65%`
- `FGR` 风机建议上限：`40 Hz`
- `FGR` 调节阀和风机频率不设置运行下限，建议目标仅做非负保护
- 普通建议步长：阀位 `2%`，风机 `1 Hz`
- 高风险建议步长：阀位 `5%`，风机 `2 Hz`

建议优先级：

1. 若预测 `O2` 低于安全下限，优先建议降低或暂缓增加 `FGR`。
2. 若预测 `NOx` 低于运行经验下限，暂缓继续增加 `FGR`。
3. 若 `NOx` 峰值或上升趋势偏高，且 `O2` 有安全裕量，则建议增加 `FGR`。
4. 若 `O2` 裕量充足且 `FGR` 未到上限，可小幅增加 `FGR` 继续压低 `NOx`。
5. 若各项指标处于约束内且裕量不大，建议保持当前 `FGR`。

注意：第一版建议不会把建议后的 `FGR` 轨迹再次送入模型做二次预测，因此界面会明确标注“未模拟调整后的二次预测曲线”。后续如果训练支持候选 `FGR` 轨迹输入的控制预测模型，可升级为离散候选搜索 MPC。
